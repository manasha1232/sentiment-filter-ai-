# sentiment-filter-ai-
AI-powered tool that analyzes social media posts for sentiment. If negativity exceeds 50%, it offers AI-generated positive rewrites. Uses VADER for sentiment analysis and DistilGPT-2 for text rewriting. Helps reduce toxic posts and encourages healthier communication online
# 😎 Sentiment Filter AI  

A simple AI-powered tool that checks negativity in social media posts.  
If negativity is **50% or more**, the app asks whether you want it **rewritten**.

✨ Rewrite engine provides:
- Soft Positive version  
- Neutral Professional version  
- Fully Positive motivating version  

---

## 🚀 Features
- Real-time sentiment scoring using VADER  
- Visual percentage bars  
- Automatic rewrite suggestions  
- T5 Transformer model for text rewriting  
- Clean Streamlit UI
